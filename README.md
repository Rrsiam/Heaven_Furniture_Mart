# Heaven Furniture Mart — Premium Landing Page

Built with:
- ReactJS
- HTML5
- Tailwind CSS
- JavaScript
- Vite

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Notes

The landing page follows the supplied RACDOX Hackathon company brief:
- One conversion-focused landing page
- Luxury / bespoke furniture studio positioning
- Responsive mobile-first layout
- Furniture collection imagery
- Request a Quote modal
- WhatsApp CTA
- Clear contact information
- Bespoke furniture as the key differentiator

The demo uses remote Unsplash images so the project works immediately. For the hackathon, replace these with Heaven Furniture Mart's real furniture/showroom/team photos from their social media for stronger brand credibility.
